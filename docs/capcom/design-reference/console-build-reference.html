Tokens

Every colour here is an ADR 0081 mission-control token — --surface-*, --status-*, --viz-categorical-*. No raw hex; the token gate (check:tokens) passes by construction.

Where it lands

Overview → new src/widgets/overview-dashboard (visx charts, ADR 0086). Events → the existing src/widgets/events-explorer, re-skinned onto the mission-control surface.

Theme decision

Dark-committed instrument panel. Adopting this app-wide moves the shell + shipped events-explorer off the neutral shadcn light default onto the --c-* layer — a theme-axis change (ADR 0092) worth its own ADR.

Data contract

Charts stay presentational: reduced rows in as props (TanStack Query over the 0084 RPCs). No aggregation in component code; funnel/segment semantics per ADR 0087/0089.
